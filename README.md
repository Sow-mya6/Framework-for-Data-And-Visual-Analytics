# Social Media Analytics Dashboard

## About the Project

This project analyzes social media engagement data using Python and Power BI. It helps understand platform performance and user engagement through charts and visualizations.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Microsoft Power BI

## Dataset

The dataset contains information about:

* Platform
* Views
* Likes
* Comments
* Shares
* Followers
* Post Type
* Date

## Dashboard Pages

1. **Page 1:** Overall Performance and Engagement Trend
2. **Page 2:** Engagement by Platform and Post Type
3. **Page 3:** Engagement Rate and Followers
4. **Page 4:** Comments and Shares by Platform

## Key Insights

* YouTube has the highest total engagement in the dashboard.
* Instagram has the highest average engagement rate.
* Engagement varies across different post types.
* Engagement changes over time.

## Conclusion

This project uses Python for data analysis and Power BI for visualization. The dashboard helps compare social media platforms and understand engagement patterns.
